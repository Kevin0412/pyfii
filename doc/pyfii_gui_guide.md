# PyFii GUI 使用引导

PyFii GUI 用于读取 Fii 工程、检查 core warning、预览二维或三维轨迹，并通过 PyFii core 渲染器导出 MP4。它不会修改上传的工程。

## 1. 准备工程

GUI 接受包含 `.fii` 文件和 `动作组/` 目录的 zip。直接把完整的 Fii 工程目录压缩为 zip，不要只压缩单个 `.fii` 文件。

本地路径导入只在部署者明确开启 `PYFII_GUI_ENABLE_LOCAL_PROJECT_IMPORT` 后出现，公网实例默认没有这个入口。

## 2. 载入与校验

在模拟器顶部选择 zip、解析帧率和是否忽略加速度，然后点击“载入”。后端会安全解压工程，通过 `read_fii()` 读取轨迹，再调用 core 无窗口渲染校验距离。

- error 表示当前操作失败，例如压缩包无效、工程无法解析或视频渲染失败；相关操作会停止。
- warning 表示工程仍可继续预览或导出。动作未完成、距离告警、默认速度以及未拼接积木等 core warning 会出现在安全日志中。
- 未拼接到 `Goertek_Start` 执行链的 Blockly 积木不会执行；GUI 会显示 core 给出的未拼接积木 warning。

安全日志支持按时间、类别、无人机和消息筛选。点击带时间的事件会跳转到对应时刻。

## 3. 预览

- “经典 2D”显示 top / front / right 三视图。
- “三维 3D”支持正交或透视相机；可拖动旋转，滚轮改变投影距离，也可直接输入视角参数。机体会根据轨迹中的加速度与重力合成方向显示倾斜姿态。
- 时间轴支持播放、暂停、倍速和拖动。
- 模拟画面右上角的全屏按钮会同时展开画面和时间轴；按 `Esc` 或再次点击按钮退出。
- 工程包含可识别音乐时，时间轴可以播放音乐。浏览器播放和轨迹是基础同步，不是专业音视频编辑器。

GUI 的交互预览使用浏览器 Canvas/Three.js；它适合快速查看和交互，不等同于 core 的 OpenCV 视频画面。

第一次进入工作台时，页面会用聚焦遮罩逐项指出上传、视图、时间轴、全屏、安全日志和导出控件。可以使用“上一步”“下一步”或键盘左右方向键浏览，按 `Esc` 关闭；之后可从工作台顶部“使用引导”重新打开。

## 4. 导出 MP4

“SSAA”只提高浏览器预览的内部渲染分辨率，不会放大机体、线条或字体。倍率越高，边缘越平滑，同时会增加浏览器渲染开销。

“导出 MP4”会创建后端渲染任务，不再录制浏览器画面。导出采用当前 2D/3D 模式和相机设置，并复用 `DroneTrack`、`FiiRender2D` 或 `FiiRender3D`；2D 导出同时采用当前 SSAA，3D 导出保持 core 渲染器的固定尺寸。

任务运行时页面显示进度条：排队阶段为 0%，逐帧渲染按真实已写入帧数推进到 95%，随后进入视频/音频封装，完成后为 100% 并开始下载 MP4。失败时页面显示真实错误。若工程音乐可由 core 识别且服务器安装了 ffmpeg，core 会尝试把音乐封装进 MP4。

当前任务状态保存在后端内存中。后端重启后，旧任务和项目缓存会失效；视频渲染也不会跨进程共享任务状态。

## 5. 编写 PyFii 脚本

最小流程是创建 `Drone`、组织动作、用 `Fii` 保存工程，再把生成工程载入 GUI。完整接口和示例请继续阅读“PyFii 文档”与“教程”的脚本模式、编队飞行和灯光章节。

```python
from pyfii import Drone, Fii, drone_config_4m

d1 = Drone(40, 40, config=drone_config_4m)
d1.takeoff(1, 100)
d1.inittime(4)
d1.land()
d1.end()

project = Fii("demo", [d1])
project.save()
```

PyFii 1.6.0会从无人机配置推断场地；旧的`field=`参数已被忽略。多机完整示例见“编队飞行”。

## 常见问题

### 为什么载入成功但出现 warning？

warning 来自 PyFii core 的解析和距离校验。它提示需要检查的内容，但不会无故阻止预览。先按类别筛选，再点击带时间的事件定位。

### 为什么有些积木没有执行？

Blockly 只执行连接到唯一顶层 `Goertek_Start` 的链。散落在工作区、没有拼接到该链的积木会被忽略并产生 warning。

### 为什么导出与浏览器 3D 画面不完全相同？

浏览器 3D 使用 Three.js 以便交互；MP4 使用 core 的 `FiiRender3D` 参考渲染器。两者消费同一份轨迹和相机语义，但绘制后端不同。

### 为什么导出没有音乐？

先确认工程元信息中显示了音乐，并确认服务器可以执行 ffmpeg。core 当前只会处理其支持且能在工程中定位到的音频文件。

### 为什么刷新后项目消失？

当前 GUI 的项目和视频任务使用进程内缓存。刷新页面不会主动删除后端数据，但后端重启或多进程请求落到另一个 worker 时，缓存可能不可用。
