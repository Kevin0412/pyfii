# PyFii 教程

- [安装](install.md)：安装 PyFii、从仓库开发和启动 Web GUI。
- [编队飞行](group_flight.md)：F400/F600 多机工程的完整示例。
- [脚本模式](script_mode.md)：生成和编辑贴近原版动作组的 Python 脚本。
- [灯光编写](light.md)：颜色、单灯、全灯、闪烁和时间戳对齐。
- [内部原理](principle.md)：`.fii`/Blockly XML 解析、轨迹模型、渲染和代码生成。

第一次使用建议先读“安装”和 [PyFii core 文档](../doc_zh_CN.md)。“内部原理”面向准备维护或复刻项目的开发者，不是使用 GUI 的前置要求。
